# Anamorphic Lens SpecStatus: APPROVED FOR IMPLEMENTATION (2026-08-25). Author: main session.Scope: three physically distinct effects of an anamorphic lens, each on its own switch:1. **Squeeze** - wider horizontal capture for the same focal length, letterboxed to the   desqueezed format.2. **Oval bokeh** - out-of-focus discs are vertical ovals, height : width = squeeze : 1.3. **Horizontal flare** - the long tinted line thrown across the frame by bright sources off   the cylindrical front element.Everything below is a delta on the current tree. Build with the bundled CMake(`Tools\CMake\Win32\bin\cmake.exe --build solutions_cmake\win64 --target <T> --config Profile`),targets `CinematicCamera` and `CryRenderD3D11`, zero warnings.
