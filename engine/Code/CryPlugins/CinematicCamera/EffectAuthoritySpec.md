Mask-kernel sampling degeneracy (symptom 3 primary cause — verified :336-348,:382-394, :167-191)The 7×7 tap loop feeds a REGULAR grid (`t.y ∈ {0..6}/6`, only 7 distinct values) into`SampleMaskKernelTap`'s row-CDF inversion → all 49 taps land on at most 7 mask rows(3×3 pass: 3 rows). Thin vertical structure (note stem) becomes discrete horizontalbands; at large CoC each band is tens of pixels from the next → "coarse notefragments". The polygon path is immune (Shirley concentric mapping is area-preserving).Fix: for `bMaskKernel` only, replace the grid (u,v) with a deterministiclow-discrepancy set — Hammersley: `u_i = (i + 0.5) / N`, `v_i = radicalInverse2(i)`(bit-reversal). N=49 first pass, N=9 second pass. Every tap then has a distinct v →CDF inversion can hit up to 49 distinct rows. Deterministic across frames (no temporalnoise). `ToUnitDisk` path keeps the existing grid (its concentric mapping wants thestratified square).### R2.
