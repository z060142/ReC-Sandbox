# Field-Dependent Pupil (cat-eye, coma, astigmatism) ??SpecificationStatus: approved for implementation, 2026-08-26. Owner of semantics: the camera manager(this document). Implementation: renderer DOF stage + tonemap + shaders + component.## 1. What this addsToday the pupil (`iris ??shape mask`, see SpriteBokehSpec / HybridDof 2.0) is evaluated as ifevery pixel looked at the lens straight down the axis. A real lens does not: rays to the edge ofthe field pass the barrel and the element rims obliquely, so the visible pupil is **clipped bythe mechanical opening**, more the further from the centre. That single fact produces, at once:* cat-eye bokeh (discs become lens-shaped, long axis tangential) toward the corners,* mechanical vignetting (less light through a clipped pupil),* edge bokeh that is dimmer than centre bokeh,* and all of it fading away as the iris is stopped down (a small pupil is never clipped).This round upgrades the pupil model from an on-axis 2D pupil to a **field-dependent pupil**, andgeneralises the per-pixel kernel transform so two further field aberrations ride on the sameplumbing: **coma** (radial comet tails, ??pupil radius簡, strongest wide open) and**astigmatism** (radial vs tangential focus split: the blur ellipse elongates radially on oneside of focus and tangentially on the other).Physically correct AND bold: defaults are 0 (no change to existing scenes), but at strength 1the corner pupil is cut to a sliver. That is the exaggeration zone by design(flaw ??suppression ??residual); the natural zone is roughly 0.2??.4.## 2. Model### 2.1 Coordinates* **Field vector** `f` of a pixel: `f = ((tc - 0.5) * 2) * (A, 1) / sqrt(A簡 + 1)`, with `A` =  render target width / height (`PS_ScreenSize.x / PS_ScreenSize.y`, or the VS equivalent).  `|f| = 0` at the frame centre, `1` at the frame corners. `u = f / |f|` is the radial unit  vector, `t = perp(u)` the tangential one. All three passes below (gather, splat, tonemap) run  on the rendered = sensor frame (the anamorphic desqueeze happens later in PostAA), so no  squeeze factor enters the field vector.* **Pupil units**: 1 = the pupil's bounding radius ??the unit the gather taps and the splat's  quad-local coordinates already use (bare iris: iris radius; with a mask: whichever hole  bounds the pupil). Physical radius of that bounding circle relative to the lens wide open:  `p = clamp(N_open / N_geo, 0.05, 1)`, `N_geo = max(N, N_mask)` (`GetGeometricAperture()`),  `N_open` = the new **Maximum Aperture** lens parameter.  Everything field-related is expressed in wide-open pupil units on the CPU and divided by `p`  to reach pupil units, so stopping down shrinks the pupil relative to the fixed barrel and the  effects vanish by themselves ??no separate "aperture link".### 2.2 Cat-eye = barrel clipThe mechanical opening is a circle of radius `R_b = 1.05` (wide-open units; cvar`r_DofCatEyeBarrel`, tuning only) whose centre, seen from field position `f`, sits at`c = -u * (K_reach * catEye * |f|)` with `K_reach = 1.5` (cvar `r_DofCatEyeReach`). In pupilunits: `c_p = c / p`, `R_p = R_b / p`.* Pupil value at pupil point `x`: `pupil(x) *= saturate((R_p - |x - c_p|) / softEdge)`,  `softEdge = 0.08` (gather) / `0.06` (splat). The band is CENTRED on `R_p` (`+ 0.5` inside the saturate) so that with Cat-eye 0 every tap of the unit pupil sits fully inside the 1.05 barrel and the clip is an exact identity.* Transmission (fraction of the on-axis light that still gets through), unit disc ??barrel:  ```  T(d, R) = area(disc(1,0) ??disc(R, d)) / ?  d >= 1 + R      -> 0  d <= R - 1      -> 1            (barrel encloses the pupil)  d <= 1 - R      -> R簡           (barrel inside the pupil; not reachable with R_b >= 1)  else A = acos((d簡 + 1 - R簡) / (2d)) + R簡 acos((d簡 + R簡 - 1) / (2dR))           - 0.5 sqrt((-d + 1 + R)(d + 1 - R)(d - 1 + R)(d + 1 + R)),  T = A / ?  ```  with `d = K_reach * catEye * |f| / p`, `R = R_b / p`. This is a shared shader function  (`LensFieldPupilTransmission(d, R)` in `PostEffectsLib.cfi`, used by DepthOfField.cfx and  HDRPostProcess.cfx ??verify both include it; if not, add the include).The clip is applied to the pupil **before** the aberrations below (it is the aperture; coma andastigmatism are what the glass does to the rays that got through).### 2.3 Where the light loss is applied ??exactly onceThis is the semantic rule of the round and the reason the spec exists:* The **tonemap vignette** darkens every pixel by `T(|f|)`. That is the one and only place the  mechanical light loss is applied, because it belongs to in-focus pixels just as much as to  blurred ones (the pupil is clipped whether or not the point is in focus).* The **gather** clips its taps (weights ? clip) and keeps its existing renormalisation by  accumulated weight. It therefore reshapes the kernel without changing brightness ??correct,  since the tonemap already carries the loss.* The **splat** divides by the full disc area (`fSplatNorm`), so clipping its pupil would dim  it by `T` automatically and the tonemap would dim it again (`T簡`). The splat therefore  **multiplies its deposit by `1 / max(T, 0.05)`**, computed in the VS from the sprite's own  field position with the same function, so gather, splat and tonemap agree to the number.* The existing exposure/T-stop path is untouched: the meter reads the axis.* The stock gather term `fOptVignettingAmount = 0.2` / `fOptVignetting` in `DofPS` is a crude  radial tap squash ??Crytek's own approximation of this effect. **Remove it** (both loops);  leaving it would stack two versions of the same thing.`Vignette Amount` / `Vignette Aperture Link` stay as they are (their math is not changed) butthey are now the *residual* falloff (glass, sensor microlenses). Update their tooltips to sayso and point at Cat-eye for the mechanical part.### 2.4 ComaThird-order transverse coma displaces a ray by an amount ??field height ? pupil radius簡, alongthe radial direction. In pupil units with the aperture folded in:`x' = x + u * (K_coma * coma * p * |f| * |x|簡)`, `K_coma = 0.6`.The `p` factor is what makes coma disappear on stopping down (?_open = ?_pupil 繚 p, and theterm is ???_open簡). At coma = 1, wide open, in the corner, a rim tap moves 0.6 radii ??a clearcomet.### 2.5 AstigmatismSagittal and tangential foci differ, so the blur ellipse is elongated radially on one side offocus and tangentially on the other:`x' = u * dot(x,u) * (1 + s * K_astig * astig * |f|簡) + t * dot(x,t) * (1 - s * K_astig * astig * |f|簡)`,`K_astig = 0.5`, `s = +1` for the far layer, `-1` for the near layer.Area-preserving to first order, so no energy bookkeeping. Not aperture-dependent (it is afocus shift, not a pupil-size effect).### 2.6 Anamorphic interactionThe gather taps arrive with `x /= S` already applied on the CPU; the splat quad is narrowed by`1/S`. The barrel clip and the aberrations are defined on the **unsqueezed** pupil, so in thegather: `x_p = (x.x * S, x.y)` ??clip / coma / astig in pupil space ??`x' = (x_p'.x / S, x_p'.y)`.In the splat PS the quad-local coordinate already *is* pupil space (the quad was narrowed), sonothing extra is needed there. `S` reaches the gather through the new constant (see 禮4).## 3.
