# Diffraction Streaks（光圈星芒）規格 — CRYENGINE 5.7 渲染器功能目標：小光圈下，畫面中的強光源長出**光圈衍射星芒**（sunstars）。這是目前整套cinematic camera 完全缺席、也是使用者點名最重要的效果。## 0. 物理與外觀基準- 星芒來自光在光圈葉片**直邊上的衍射**：N 片葉片，N 為偶數 → N 道星芒；  N 為奇數 → 2N 道（每邊產生一對，偶數時兩兩重合）。- 光圈越小衍射越明顯：f/5.6 以下幾乎不可見，f/8 開始浮現，f/11–f/22 明顯而銳利。- 星芒方向垂直於葉片邊：整組隨葉片相位旋轉；道與道等角分佈（360°/道數）。- 亮度沿星芒指數衰減，長度與光源強度、光圈檔數正相關。- 只有**遠超過白點的 HDR 亮部**（太陽、燈、強烈鏡面反射）該長星芒；  一般亮的天空不該整片拉線——閾值要高。## 1. 落點：Bloom stage 的追加 pass檔案：- `Code/CryEngine/RenderDll/XRenderD3D9/GraphicsPipeline/Bloom.cpp/.h`（pass 編排）- `Engine/Shaders/HWScripts/CryFX/HDRPostProcess.cfx`（新 technique）- `Code/CryEngine/RenderDll/Common/PostProcess/PostEffects.h/.cpp`（新 post params）- CVar（除錯開關）：`RendererCVars.cpp` 加 `r_HDRStreaks`（int，預設 1，0=關）管線（CE3 HDRStreaks 的譜系，現代化重寫）：1. **StreakInput**：從 bloom 已有的縮圖鏈取 1/4 或 1/8 解析度 HDR 縮圖，   套高閾值（`threshold`，單位為 scene HDR 值）＋軟膝，輸出到一張暫存 RT   （複用 bloom 的暫存池，格式同 bloom RT，R11G11B10F 即可）。2. **方向拉伸**：對每個方向 d（角度 = bladePhase + k·360°/道數，k=0..道數-1）   執行 2–3 次疊代的可分離拉伸模糊：每次疊代沿 d 取 4–8 tap，   tap 距離按疊代次數指數放大（`stride = base^iteration`），權重指數衰減   （`w = decay^tapIndex`）。兩張 RT ping-pong。   - 效能上限：道數上限 8（葉片 16 片偶數 → 16 道太多，clamp 到 8 並在     spec 常數註明；奇數葉片 2N 同樣 clamp）。3. **合成**：所有方向結果以 max 或 add（用 add，除以道數正規化）合入   bloom 的最終貼圖，乘 `amount`，之後走既有 bloom 合成路徑——   **不要**另開 tonemap 合成點，讓它像 bloom 的一部分。## 2. 參數（post effect params，命名沿用 Dof_User 慣例）| Param 名 | 預設 | 意義 ||---|---|---|| `HDR_Streaks_Active` | 0 | 0/1，總開關（由 plugin 寫入） || `HDR_Streaks_Amount` | 0 | 0–1 強度；plugin 由光圈計算後寫入 || `HDR_Streaks_Count` | 8 | 道數（已含奇偶換算與 clamp，plugin 算好送進來） || `HDR_Streaks_Angle` | 0 | 整組旋轉（rad），= 葉片相位 || `HDR_Streaks_Threshold` | 4.0 | HDR 閾值（scene 值），越高越只挑最亮的 || `HDR_Streaks_Length` | 0.5 | 0–1，映射拉伸疊代的 stride 尺度 |PostEffects 裡掛在既有 `CHDREyeAdaptation`…不，掛在 `CFilterSharpening` 旁新建一個輕量 `CHDRStreaks : CPostEffect` 只當參數容器（模式照 `CDepthOfField` 的參數註冊；不需要 Render() 實作，pass 由 Bloom stage 讀參數執行——同 DOF stage 讀`SDepthOfFieldParams` 的模式，新增 `SHDRStreaksParams` struct + `GetParams()`）。## 3. 光圈耦合（plugin 端，CinematicCamera）plugin 在 finalize hook（`ApplyFilmGrain` 旁）每幀寫入：```道數  = (blades % 2 == 0) ? blades : blades * 2，clamp 3..8（超過 clamp）amount = saturate((N − 5.6) / (22 − 5.6))^1.5      // f/5.6 起浮現、指數走強length = 0.25 + 0.5 * saturate((N − 8) / 14)       // 越小的光圈星芒越長越利angle  = 新屬性 Blade Rotation（度，預設 0）Active = EnableStreaks 屬性（預設 true）且 amount > 0.001```存還原：與 DOF/grain/MB 相同模式（save-once/restore，Deactivate/OnShutDown/RESET/換相機全覆蓋）。plugin 端這些寫入在官方渲染器上是 no-op（未知參數名），與既有凍結策略一致。## 4. Shader 實作要點（HDRPostProcess.cfx）- 新 technique `HDRStreakThreshold`（閾值+軟膝）與 `HDRStreakStretch`  （單方向拉伸，方向與 stride 由常數 `vStreakParams` 傳入）。- 拉伸 pass 用 `GetTexture2DLod` 固定 mip，避免 aniso 干擾。- 權重總和正規化，確保能量不因疊代數改變。- 顏色保留輸入色（光源本色），不要染白。- 注意 `/W3 /WX`：float 常數帶 f、無未用變數。## 5. 驗收1. f/2.8：無星芒。f/8：隱約。f/16：清晰銳利的星芒，長度隨光圈變小而增。2. 9 葉片 → 18 道會被 clamp 到 8 道（記錄在 log 或註解，不是 bug）。   偶數 8 葉片 → 8 道，方向隨 Blade Rotation 旋轉可見。3. 只有太陽/燈等 HDR 強亮部長星芒；亮天空不整片拉線（調 Threshold 驗證）。4. `r_HDRStreaks 0` 或 plugin `EnableStreaks` 關 → 完全無成本路徑（早退）。5. Profile/Debug/Release 三 config 建置零警告；效能：1080p 下 streak pass 群   < 0.5ms（1/4 解析度、8 方向 × 3 疊代內）。6. 官方 DLL 相容：plugin 在未改的渲染器上不崩不警告（參數寫入為 no-op）。## 6. 建置與部署- 只用內附 CMake（`Tools\CMake\Win32\bin\cmake.exe`），target `CryRenderD3D11`  （shader .cfx 不用編，引擎執行期編譯；改 .cfx 後刪除  `user/shaders/cache` 可強制重編——部署說明裡註明）。- 部署：`bin\win_x64\CryRenderD3D11.dll` → 兩個引擎位置前**先備份**  原檔為 `.official-backup`（若已存在備份則不要覆蓋備份）。- Shader 檔部署：`Engine/Shaders/HWScripts/CryFX/HDRPostProcess.cfx` →  `S:\Crytek\crytek\cryengine-57-lts\5.7.1\engine\Shaders\HWScripts\CryFX\`  （同樣先備份原檔）。- 不 commit——渲染器變更由使用者實測後才收。
