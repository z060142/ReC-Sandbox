# Lens Ghosts ??SpecificationStatus: approved for implementation, 2026-08-26. Owner of semantics: the camera manager.Re-uses the sprite bokeh splat pass (SpriteBokehSpec / HybridDof 2.0 / FieldPupilSpec /AxialChromaticSpec): ghosts are drawn by the SAME pixel shader as the bokeh sprites, so theycarry the iris polygon, the shape mask and its rotation, the anamorphic oval, the cat-eye clipand the axial CA rim for free. Only the vertex shader differs.## 1. What this addsA strong light in the frame reflects between the lens surfaces and lands on the sensor as achain of **images of the aperture**, strung along the line from the light through the framecentre and out the other side. Every element pair adds one ghost with its own size and itscoating's colour. Modern multi-coated glass shows them faintly; vintage and anamorphic glassshows them boldly.Screen-space HDR extraction, not light-entity flares: anything bright enough ??a lamp, anemissive surface, a reflection ??spawns ghosts, and they read the true pupil shape.## 2. ModelFor a bright source at NDC position `P` (frame centre = 0), ghost `i` of `N` sits at`G_i = -P * k_i`,   `k_i = spread * lerp(0.3, 1.6, i / max(N - 1, 1))`(so the chain runs from near the centre to past the opposite edge), with radius`r_i = size * lerp(0.6, 1.4, i / max(N - 1, 1)) * H * 0.05 * p`in pixels (`H` = frame height, `p` = pupil scale `N_open / N_geo` ??a ghost is an image of theaperture, so it shrinks when the iris closes), colour`c_i = excess * amount * tint rotated in hue by i * hueSpread * 120簞`(`excess` = the source's luminance above the ghost threshold with the same quadratic knee thesplat uses, times `p簡` - the energy a ghost carries goes with the aperture AREA like everythingelse the lens passes, and since the disc area is also ??p簡 the per-pixel brightness relative tothe scene is constant at every f-number: stopping down makes ghosts smaller and harder-edged,never brighter (the first cut lacked this and produced blazing specks at f/8 that then grewstreaks); the bokeh splat's user Highlight Gain is divided out so presets do not couple; the hue rotation is the cheap stand-in for different coatings on differentsurfaces ??one base tint, the rest fan out around it), deposited energy-conservingly over thedisc exactly as a bokeh sprite is (`fSplatNorm` with `QuadPos.w = r_i`, `Field.z`, dither).Ghosts are formed in the lens, not in the scene: they are NOT depth-masked and NOT blurred bythe depth of field. They go into the **near** splat layer (`QuadPos.z = 1`), which the overlayadds unmasked; the far layer is depth-masked against in-focus foreground and would cut them.## 3. Renderer### 3.1 Pass structure (`DepthOfField.cpp`)`ExecuteSpriteBokeh` becomes `ExecuteSplatLayers(bool bSplat, bool bGhost)`: acquire + clearthe layers, draw the bokeh splat if `bSplat` (`CV_r_DofMode == 0`, as today), draw the ghostlayers if `bGhost` (`fGhostAmount > 0.001`), then the existing overlay composite. `Execute()`calls it when either is true. All the per-frame constants the splat resolves (`vAspectRatio`,`vDofBokehShape`, `vDofBokehMask/2`, `vDofFieldPupil/2`, `vDofAxialChromatic`, the pupil-fillgain division) are resolved once and shared by both draws ??that is the point of the re-use.Ghost draws: technique `DofBokehGhost` = new VS `DofBokehGhostVS` + the existing`DofBokehRefPS`, one `CRenderPrimitive` draw per ghost layer (`N <= 6`), each with its own`vDofGhost0 = (k_i, r_i, threshold, knee)` and `vDofGhost1 = (tint_i.rgb, amount)`. The gridis **quarter resolution** (one quad per 4x4 native pixels; its own per-view CB / viewport likethe splat's half-res grid): ghost sources are large and the layers multiply the vertex work.Same render state (additive), same textures (scene target t0, depth t1 unused, dither t2,shape t3), same PS constants.Once-per-change log: `[DOF] ghosts n=%d amount=%.2f spread=%.2f size=%.2f thresh=%.1f`.### 3.2 `DofBokehGhostVS` (DepthOfField.cfx)Mirror of `DofBokehRefVS` with these differences:* Cell ??`screenProj` as today (the grid is quarter res through the per-view CB, so the  existing integer walk works unchanged); the four selection taps sit at 簣0.5 native texel  around the cell centre (the middle 2x2 of the 4x4 cell).* Threshold / knee from `vDofGhost0.zw` (not `vDofBokehHighlight`); cull on zero excess.* No CoC read, no fade, no depth: `fRadiusPx = vDofGhost0.y`; cull if `< 1`.* Position: `OUT.Position.xy = -vOutPos.xy * vDofGhost0.x` (NDC mirror through the centre),  then the quad expansion exactly as the splat (`QuadPos.xy` from the radius in pixels ?  `g_VS_ScreenSize.zw * 2`, `vAspectRatio.xy`, the squeeze `vAspectRatio.z`, the field growth  `g`, `Field = (f, 1/T, g)` computed from the GHOST's position, not the source's).* `QuadPos.z = 1` (near layer), `QuadPos.w = fRadiusPx`, `Color.w = sqrt(fRadiusPx)`.* `Color.rgb = cExcess * 0.25 * vDofGhost1.rgb * vDofGhost1.w`.### 3.3 ParametersNew component group `SCineGhostParams` "Lens Ghosts" (own GUID, 4CC ids not colliding):| Member | Label | Range | Default | Tooltip gist ||---|---|---|---|---|| `amount` ('ghAm') | Amount | `Range<0, 2, 0, 1>` | 0 | Strength of the internal-reflection ghosts. 0 = off (no pass runs).
