# Halation SpecStatus: APPROVED FOR IMPLEMENTATION (2026-08-25). Author: main session.Repository: `E:\coding3\ReC_sandbox\CRYENGINE_Source`, branch `dev`.## What it isOn film, light from a very bright source passes through the emulsion, reflects off the filmbase and re-exposes the emulsion around the source. The red-sensitive layer sits deepest, sothe halo is red-orange, it is much wider than the bright core itself, its edge is soft, and itonly appears around sources that genuinely overload the emulsion (not around a bright sky).It is a property of the film stock, not of the lens, so it does not follow the f-number.Implementation: a bloom-domain pass next to the diffraction streaks - threshold the scene at ahalation threshold, blur wide, tint, add into the bloom target with the same bloom-weightcompensation the streaks use.
